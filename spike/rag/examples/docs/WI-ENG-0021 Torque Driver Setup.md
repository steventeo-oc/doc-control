# WI-ENG-0021 Torque Driver Setup

1. Purpose

This work instruction explains how to set and verify a torque driver before fastening server chassis screws.

3. Steps

3.1 Setting the Torque

Select the torque value from the fastener table. Chassis cover screws are tightened to 0.6 Nm. Rack ear screws are tightened to 1.2 Nm.

3.2 Verification

Verify the driver on the torque tester at the start of every shift. If the reading is outside plus or minus 5 percent, tag the driver and return it to the calibration cabinet.

3.3 Calibration Label

Check that the calibration label is in date before use, as required by SOP-QA-0010.
